## Catalog and goals
12 immutable definitions in3groups of4. ID1..12; first open, next opens after previous Bronze; replay any earned/unlocked trial. No time gate, payment, ad or coin reward required to retry; a fresh run restores its3attempt budget after completion/exhaustion or explicit abandonment. Every run is exactly one selected trial; its attempt budget does not imply a daily/lifetime limit.

Each group contains Steady, Fragile, Drift, Wind using existing block kinds: Steady allStandard; Fragile every second blockFragile; Drift allDrift; Wind allWind. Group0 targets8/9/10/11, group1targets10/11/12/13, group2targets12/13/14/15; widths3.6/3.4/3.2; speed group1.10/1.25/1.40 plus0.04×column. Existing motion and geometry remain authoritative; trial definition sets width/speed/kind and disables charged powers/risk for fair fixed goals only inside Trials. No changes to original abilities/unlocks.

Goals rotate by trial ID: Perfect count, longest Perfect streak, retained top area. Perfect-count bronze ceil(target×0.40), silver ceil(target×0.60), gold ceil(target×0.80). Streak bronze2, silver4, gold6. Retained area bronze0.35, silver0.55, gold0.75 of starting width². Only a fully completed tower can receive a medal; a miss or completion below Bronze consumes an attempt with clear result. Nonfinite/out-of-range/impossible stats/geometry reject. Best medal never decreases. No old stars, coins, Best, Towers, unlocked levels, daily claims, earned-style ownership or commerce receipt fields are granted/mutated by trial events.

## Pure state machine
System-only C# domain in Assets/Scripts/Gameplay/TowerTrials.cs. DTOs TrialDefinition, TrialLayer (CenterX/CenterZ/SizeX/SizeZ), TrialSnapshot (Placed,Perfects,Streak,MaxStreak,Phase,Layers), TrialSession (RunId,TrialId,AttemptId,AttemptNumber,State,Snapshot,Medal), TrialRecord (TrialId,BestMedal,CompletedRuns,Attempts), TrialBook (Schema1,Revision,Records,Active). States Running,Failed,GoalMissed,Cleared,Abandoned. GUID-N identities and explicit run+attempt tokens; no Unity objects/references or mutable shared snapshots.

TrialRules.Begin(book,trialId,runId,attemptId): checks unlock and no unfinished active run; new attempt1. Retry(book,runId,oldAttemptId,newAttemptId): only Failed/GoalMissed with attempts<3; fresh snapshot, increment budget exactly once. Checkpoint(book,runId,attemptId,snapshot): only active matching Running; count same or+1, finite valid geometry/count/streaks; phase changes with same settled geometry allowed; clone all inputs. Finish(book,runId,attemptId,snapshot,failed): matching active only, derives medal from actual snapshot; terminal exact callback retry returns same book, changed payload or old/foreign token rejects. New run makes every older callback stale. Abandon explicitly retains aggregate medal/attempt records and marks current session abandoned; no implicit paid refill. Checked counters reject overflow.

Actual StackRun placements remain in Unity adapter; pure harness tests mode/goals/state/serialization/storage, not a replacement fake geometry engine. Engine validation must subsequently compare actual StackRun→TrialSnapshot transitions for each modifier and ensure old gameplay/economy unchanged. Trial run snapshot retains bounded<=15actual settled layers plus motion phase, without powers. Terminal snapshots are retained for result/retry; cold resume only Running.

Original StackSave JSON, jump namespace, preferences, receipts and all old fields remain on original paths.
